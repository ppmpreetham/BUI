# {{title}}

A [BUI](https://bui.preetham.top) app: native windows from JavaScript, with no browser or Electron.

```sh
bui dev            # run it and restart on every save
bui build          # one small executable (about 5 MB)
bui doctor         # check the setup, and fix what is wrong
bui update         # update bui and this project's packages
```

The scripts in `package.json` are what those run (`dev`, `build`, `lint`, `format`, `fix`).

# {{title}}

A [BUI](https://bui.preetham.top) app in Python.

```sh
bui dev                    # run it (uv run main.py)
bui doctor                 # check the setup, and fix what is wrong
bui update                 # update bui and this project's blenderui
uv run ruff check .        # lint
uv run ruff format .       # format
```

`uv` keeps the Python version, the virtual environment (`.venv`) and the lock file (`uv.lock`).

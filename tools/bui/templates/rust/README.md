# {{title}}

A [BUI](https://bui.preetham.top) app in Rust.

```sh
bui dev            # run it (cargo run)
bui build          # a release build (cargo build --release)
bui doctor         # check the toolchain and the project, and fix what is wrong
bui update         # update bui and this project's blenderui
cargo clippy       # lints (pedantic is on, see Cargo.toml)
cargo fmt          # format
```

Here's the honest picture. Most of BUI works today, a few parts are partial, and some are still plans. This page tells you which is which, so you never have to guess.

Each row has a status: **Works** when it works and is tested, **Partial** when common cases work but pieces are missing, **Experimental** when it's written but not yet proven on real hardware, and **Planned** when it's planned but not built.

## Help make it happen

The quickest wins are the experimental rows: if you use Wayland, trying the native Wayland host and reporting what happens is enormously useful. On a Mac with an older macOS, the [macOS testing guide](https://github.com/ppmpreetham/BUI/blob/main/docs/macos-testing.md) walks you through it. Bug reports, missing tkinter or Qt behaviour, CSS features and docs are all welcome too. Start with [CONTRIBUTING.md](https://github.com/ppmpreetham/BUI/blob/main/CONTRIBUTING.md).

BUI is free software. You can use it, study it, change it and share it. It exists because thousands of people built Blender's interface over decades and shared it under a free license; BUI keeps that promise going.

## BUI's license: GPL-3.0-or-later

BUI is derived from Blender's source code, so it follows Blender's licensing: BUI as a whole is licensed under the **GNU General Public License, version 3 or later**, and individual files may have a different, but compatible license. The files that come from Blender keep Blender's SPDX header, and new files carry the same one:

```c
SPDX-License-Identifier: GPL-2.0-or-later
```

The Python package (`pyproject.toml`), the Rust crates (`Cargo.toml`) and the npm packages (`package.json`) all declare `GPL-3.0-or-later`, the license of the whole. The repository's `LICENSE` file holds the text of version 3 of the GNU GPL. A file that says `GPL-2.0-or-later` can be combined into that whole, which is how Blender itself is licensed.

### What it means for you

In plain words, and not as legal advice:

- **Using BUI** to build and run your own programs is free, for any purpose, commercial included.
- **Changing BUI** is free too.
- **Distributing** a program that includes BUI (shipping an app, publishing a package) means distributing it under the GPL as well, with its source code available to the people you give it to.

If you need different terms, ask a lawyer before you ship.

### Contributing

Contributions are accepted under the same license, and new files carry the same SPDX header. See [Contributing](../contributing/).

## Third-party parts

Some parts of BUI come from other projects and keep their own licenses:

| Part | What it does in BUI | License |
| --- | --- | --- |
| [Blender](https://www.blender.org) sources | Widget drawing, interaction rules, theme, icons, `blenlib`, GHOST window code, the file browser and node editor | GPL-2.0-or-later |
| [Dear ImGui](https://github.com/ocornut/imgui) by Omar Cornut | The immediate-mode GUI that runs on BUI | MIT |
| [Inter](https://rsms.me/inter) by Rasmus Andersson | The embedded UI font, as in Blender (`gpu/extern/Inter-LICENSE.txt`) | SIL Open Font License 1.1 |
| [FreeType](https://freetype.org) 2.13.3 | Glyph loading, hinting and rendering, like Blender's BLF | FreeType License or GPLv2 (dual-licensed) |
| [stb_truetype](https://github.com/nothings/stb) by Sean Barrett | Font metrics, and the fallback text rasterizer | Public domain |
| [NanoSVG](https://github.com/memononen/nanosvg) by Mikko Mononen, as edited by Blender | Rasterizing Blender's SVG icons and SVG images | Zlib |
| [Wuffs](https://github.com/google/wuffs) (Google) | Decoding PNG, GIF, BMP, TGA and QOI (`kit/extern/wuffs`) | MIT or Apache-2.0; BUI uses it under MIT |
| [libjpeg-turbo](https://libjpeg-turbo.org) 3.1.2, decoder only | Decoding JPEG (`kit/extern/libjpeg-turbo`) | IJG License, BSD-3-Clause and zlib (see its `LICENSE.md`) |
| [libwebp](https://chromium.googlesource.com/webm/libwebp) 1.6.0, decoder and demux | Decoding WebP (`kit/extern/libwebp`) | BSD-3-Clause, with Google's patent grant (`PATENTS`) |
| [Slug](https://github.com/EricLengyel/Slug) by Eric Lengyel | The GPU glyph coverage algorithm (shader code "Copyright 2017 by Eric Lengyel") | MIT |
| [Tailwind CSS](https://tailwindcss.com) | The v4 default theme values behind the Tailwind support | MIT |

The Rust and JavaScript bindings also depend on crates and packages such as taffy, napi-rs, React and QuickJS, each under its own license.
